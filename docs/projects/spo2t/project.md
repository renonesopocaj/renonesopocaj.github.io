# Edge AI for Obstructive Sleep Apnea Detection Repo

This project was developed in one day for the Bosch x NecstLab Hackathon, won the "Best idea prize".
We deployed an MLP to detect sleep apnea from SpO2 data on an Arduino Nicla with MAX30102 pulse oximeter, converting 
the ONNX model via Zant SDK into a precompiled embedded runtime, achieving 10 ms inference.  

[GitHub repository](https://github.com/renonesopocaj/spo2t)
